## 本轮已修复 / 已实现

### 本机代码改动（T1 实现，engineer）
| 文件 | 要点 |
|---|---|
| `docker-compose.yml` / `docker-compose.publish.yml` | client 服务新增 `volumes: - "${CERT_DIR:-./certs}:/etc/nginx/ssl:ro"`；端口/healthcheck/logging/network 不变 |
| `nginx.conf` | 两个 443 server 块统一指向 `/etc/nginx/ssl/fullchain.pem` + `privkey.pem`（SAN 单证书）；80 块/TLS/HSTS/SPA/health 不动 |
| `Dockerfile` | 删除两条 BuildKit secret 证书 RUN（镜像不再含私钥）；`mkdir -p /etc/nginx/ssl && chown nginx:nginx` 保留 |
| `rebuild.py` | 删除 `SSL_SECRETS`、base64 导入与编码循环、`--secret` 追加逻辑 |
| `restart.py` | `up -d` 前校验证书目录（`certs/fullchain.pem` + `privkey.pem` 缺失即 sys.exit 报错） |
| `.env` | 删除旧 `SSL_NYAA_HOST_CRT`/`SSL_NYAA_HOST_KEY` 占位；新增可选 `CERT_DIR=./certs`（DNSPod 凭据绝不写入） |
| `acme/deploy_certs.py`（新建） | 到期时间打印 + 证书存在非空校验 + 权限固化(644/600/root) + `nginx -t`(失败中止) + `nginx -s reload` + 写 `acme/renew.log`；容器未运行仅警告跳过 reload |
