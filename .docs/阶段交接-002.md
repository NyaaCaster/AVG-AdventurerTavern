## 故障现象

浏览器访问 `https://h.nyaa.host:3096/` **页面能正常打开，但全部美术资源（立绘/背景/头像）与音频加载失败**。用户要求判定：是本机（Windows）资源服务问题，还是 macmini 容器服务问题。

## 根因（结论：macmini 容器侧，非本机）

美术/音频资源**不在前端镜像里**，而是由 macmini 上的 **`adv-file-server` 容器（5101/5102/5103）** 提供：

- `utils/imagePath.ts:10` 硬编码 `PROJECT_BASE_URL = "https://h.nyaa.host:5102/files/"`；`config.ts:11` 的 `fileServer.baseUrl` 也是 `:5102`。
- 该容器的 nginx 证书来自宿主 `/root/DockerContainer/AVG-AdventurerTavern/ssl/`（**旧 TrustAsia 证书**，且 nginx.conf 硬编码文件名 `h.nyaa.host_bundle.crt`），该证书 **2026-08-31 04:59:59 GMT 到期**（同目录 h.hony-wen.com 版 08-25 到期）。
- 而 `acme/reload_certs.py`（acme.sh reloadcmd）**只覆盖** AVG `certs/` + MyToken `certs/` + Caddy，并只 reload `adventurertavern`/`mytoken-web`/`caddy-ollama` —— **完全没有 file-server 分支**，`ssl/` 目录自 2026-07-09 起无人更新。
- 结果：前端页面（3096，用新的 LE SAN 证书）正常，资源域（5102）证书过期 → 浏览器 `SEC_E_CERT_EXPIRED` 拒绝加载 → **「页面能开、无美术」**。

**排除本机因素**（证据）：
- macmini `adv-file-server` access log 记录到来源 `192.168.31.142`（本机）的 `GET /files/...`；本机 `netstat` 仅有到 `192.168.31.141:5102` 的连接。
- 本机无 3096/5102 监听、无酒馆/美术资源容器（本机 `file-server` 容器是 NyaaChat 的 5100，其 `Files/` 为空，仅 `.gitkeep`）。
- 资源本体完好：macmini `DockerRes/AVG-AdventurerTavern/file-server` 共 2.4 GB / 2417 文件（`img/{bg,char,char-hd,face,drinks,foods,icon,inn_food,quest,svg,ui}` + `audio/bgm`）。
